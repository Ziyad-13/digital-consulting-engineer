## 2024-05-19 - Streamlit Disabled Button Tooltips
**Learning:** In Streamlit applications, `st.button` components do not natively or easily accept standard HTML `aria-label` tags due to how the framework renders React components underneath. However, Streamlit provides a native `help` parameter (`st.button(..., help='tooltip text')`). When a button is `disabled=True`, providing this `help` string renders a tooltip that effectively communicates *why* the element is disabled, significantly improving both accessibility (providing context to screen readers via generated attributes) and general user experience for blocked actions.
**Action:** Always utilize the `help` parameter on Streamlit interactive elements (like buttons or inputs) when they are conditionally disabled to provide immediate inline context, rather than relying solely on decoupled alerts or warning banners.
