## 2024-10-24 - Accessible tooltips for disabled Streamlit buttons\n**Learning:** Streamlit button components do not natively support injecting `aria-label` attributes. To provide context to users and screen readers on *why* a button is disabled, the native `help` parameter should be utilized. It dynamically renders a tooltip with explanatory text.\n**Action:** Use the `help` parameter to present required dependencies or blocked reasons whenever disabling an actionable element like a button in Streamlit.
